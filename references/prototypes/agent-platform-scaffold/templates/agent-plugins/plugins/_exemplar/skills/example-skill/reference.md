## Types

| Type | Use for |
| --- | --- |
| `feat` | A change a user would notice |
| `fix` | A correction to behaviour that was wrong |
| `chore` | Maintenance with no behavioural change |
| `docs` | Documentation only |
| `refactor` | Restructuring with no behavioural change |
